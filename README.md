# 摆摊记账

一个给你自己用的摆摊经营管理小工具：**商品、进货、卖货流水、成本、库存、每日利润核算、利润**，以及**库存预警（含"预计几天后用完"）**。原材料支持**规格**（每件克重），可按件或按克记用量；「核算」页把商品（原材料+成品）列成清单、直接填用量即自动算成本，再按微信/支付宝/现金记营业额，自动算每日利润，还能「盘点校正」修正称重偏差。

- 数据**只保存在手机本机**，不上传任何服务器。
- 安卓和 iPhone 都能用（浏览器打开）。
- 不需要服务器、不花钱。
- 第一次打开后**离线也能用**。
- 两台手机靠「导出备份文件 → 微信发过去 → 导入」来同步。

---

## 一、最快试一下（在电脑上）

直接双击 `index.html`，用 Chrome 或 Edge 打开就能用。功能都能点，数据会存在浏览器里。

> 说明：这样打开没有「离线缓存」和「桌面图标」，只适合先体验。真正装到手机上要按下面做。

## 二、装到手机上（正式使用）

把整个文件夹放到一个**免费网页托管**上，手机就能访问。推荐 GitHub Pages（免费、不用梯子、不用绑卡）。

### 第 1 步：注册 GitHub（只要一次）

1. 打开 https://github.com ，点「Sign up」注册一个免费账号（用邮箱，不花钱）。
2. 登录后，点右上角「+」→「New repository」。
3. 仓库名随便填，比如 `baitan`，选 **Public**，其他都不用动，点「Create repository」。

### 第 2 步：上传文件

新仓库建好后，页面上有一个「uploading an existing file」的链接，点进去：

1. 把本文件夹里的这些文件**全部拖进去**：
   `index.html`、`styles.css`、`db.js`、`app.js`、`sw.js`、`manifest.webmanifest`，以及整个 `icons` 文件夹。
2. 拖完后点「Commit changes」。

### 第 3 步：打开 GitHub Pages

1. 在仓库页面点 **Settings** → 左侧 **Pages**。
2. 「Branch」那里选 `main`（或 `master`），文件夹选 `/ (root)`，点 **Save**。
3. 等 1~2 分钟，页面上会出现一个网址，形如：
   `https://你的用户名.github.io/baitan/`

### 第 4 步：装到手机

- **安卓**：用 Chrome 打开那个网址 → 右上角菜单 →「添加到主屏幕」。
- **iPhone**：用 Safari 打开那个网址 → 点底部「分享」按钮 →「添加到主屏幕」。

以后点桌面图标就能用，跟 App 一样，而且没网也能用。

## 三、两台手机怎么同步

两台手机各自打开同一个网址、各自用（数据各存各的）。要同步时：

1. 手机 A：**设置 → 导出备份**，得到一个文件（会自动下载，建议顺手发到微信收藏）。
2. 用**微信**把这个文件发给手机 B（发「文件传输助手」或直接发对方微信号都行）。
3. 手机 B：微信里点开那个文件 → 右上角「…」→「保存到手机」（存到「下载 / Download」文件夹）；然后打开 app → **设置 → 导入备份** → 选那个文件。小米手机找不到文件时，在导入的文件选择里选「全部文件 / 下载」位置找，别在微信的隐藏目录里翻。
4. 完成，两边数据一致。

> 导入会覆盖手机 B 当前的数据，但会自动先留一份「可撤销的快照」（设置里可点「撤销上次导入」）。

---

## 四、怎么更新（以后改动了）

改代码后，把 `sw.js` 顶部的 `CACHE_VERSION = 'v27'` 改成 `'v28'`（每次加 1），重新上传覆盖文件。用户下次联网打开时会自动更新。

## 五、文件说明（不用管，备查）

|---|---|
| `index.html` | 页面骨架 |
| `styles.css` | 样式 |

## 六、数据安全提醒

数据只在你手机浏览器里，**换手机、清浏览器、卸载浏览器都会丢**。所以请养成习惯：**定期「导出备份」存到微信收藏或云盘**。
